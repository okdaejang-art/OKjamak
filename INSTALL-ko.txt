옥자막 v1.6 — 한국어 자막 편집기
버전 1.6.0 / build 21

설치 조건과 구성
• macOS 15 이상. Intel / Apple Silicon 실행 파일을 함께 포함합니다.
• 독립 앱과 Final Cut Pro Workflow Extension을 함께 제공합니다.
• OKjamak.app, 옥자막 제거.app, 사용 안내와 변경 내역이 들어 있습니다.
• 기본 Whisper Base 모델이 포함되어 있어 추가 모델 없이 시작할 수 있습니다.
• 추가 모델은 앱에서 선택하여 다운로드합니다. 모델 다운로드에는 인터넷이 필요합니다.

처음 설치
1. DMG를 열고 OKjamak.app을 ‘응용 프로그램’으로 드래그합니다.
2. 응용 프로그램 폴더의 OKjamak.app을 엽니다.
3. 파컷에서 쓸 때는 확장 메뉴의 ‘옥자막’을 엽니다.
   확장이 보이지 않으면 앱을 한 번 실행하고 파컷을 재시작하세요.
4. 파컷 프로젝트 하나를 상단 영역에 놓거나 FCPXML·영상·음성 파일을 엽니다.
5. 음성 준비가 끝나면 모델을 고르고 ‘한국어 받아쓰기’를 누릅니다.
6. 자막을 수정하고 ‘파컷으로 보내기’ 또는 SRT 내보내기를 사용합니다.

처음 열 때 macOS가 실행을 차단하는 경우
이 배포본은 Apple Developer ID 서명·공증을 받지 않았습니다.
파일의 출처를 확인한 뒤 시스템 설정 > 개인정보 보호 및 보안에서 해당 앱의
‘확인 없이 열기’를 이용하세요. 시스템 보안 기능 전체를 해제할 필요는 없습니다.

기존 옥자막 1.0.x / 1.5 / 1.6 시험판에서 업데이트
1. 현재 작업을 저장하고 옥자막과 파컷을 종료합니다.
2. 필요한 기존 프로젝트와 이전 설치 파일을 보관합니다.
3. 응용 프로그램의 OKjamak.app을 v1.6 앱으로 교체합니다.
4. 앱 상단에 v1.6가 표시되는지 확인합니다.
일반판의 앱 식별자와 설정·모델 저장 위치는 유지합니다.
기존 사용자 단축키는 유지하고 새 음성 듣기 동작만 충돌 없는 키로 추가합니다.
업데이트 전에 제거 앱을 실행하지 마세요. 폴더 권한을 요청하면 기존 미디어 폴더를 선택하세요.

음성기준 / 음성편집 시험판에서 작업 가져오기
일반판은 시험판과 별도 앱입니다. 시험판 앱과 데이터는 자동으로 삭제하지 않습니다.
시험판에서 작업을 .okjamakaudio 또는 .okjamakedit로 저장한 뒤 v1.6의 ‘프로젝트·영상 열기’로 엽니다.
가져온 시험판 작업은 .okjamak 파일로 따로 저장합니다. 자막을 다시 받아쓸 필요는 없습니다.
시험판에서 받은 모델은 모델 관리의 기존 모델 폴더 연결 기능으로 재사용할 수 있습니다.
자동 복구본과 모델을 시험판에서 자동으로 복사하거나 옮기지는 않습니다.
새 빈 클립이 포함된 작업은 v1.5 또는 이를 지원하는 음성편집 버전에서 사용하세요.

자막 편집과 단축키
• 자막 목록에서 바로 글자를 수정합니다. ↑↓는 이전·다음 자막 맨 앞으로 이동합니다.
• 문장 맨 앞에서 Space: 미리보기 재생·정지. 문장 중간에서 Space: 띄어쓰기.
• 타임라인/상세 파형 왼쪽 클릭: 재생을 멈추고 위치만 지정합니다. 자동 재생하지 않습니다.
• 전체 타임라인 Space: 미리보기 재생·정지.
• 상세 파형 Space: 현재 위치부터 음성 재생·정지. 다시 누르면 이어 듣습니다.
• 상세 파형의 흰 선은 재생 위치, 노란 선은 분할점입니다.
• 문장에 커서를 놓고 파형에서 시간을 고른 뒤 ‘여기서 분할’을 누릅니다.
  글자는 문장 커서에서, 시간은 노란 선에서 나뉩니다.
• 상세 파형에서 Space로 멈추면 그 자리를 분할점으로 사용할 수 있습니다.
• Enter로 즉시 나누면 시간은 글자 비율로 추정합니다. 주황 점선을 듣고 조절하세요.
• ‘앞을 빈 클립으로’: 노란 선 앞을 자막 없는 구간으로 만들고 문장을 뒤에 둡니다.
  원본 음성·영상과 뒤 자막 시간은 유지됩니다. 빈 자막은 파컷/SRT에 내보내지 않습니다.
• 앞 자막과 합치기: 문장 맨 앞 Backspace. 줄바꿈: Shift+Enter.
• 파형 양 끝의 손잡이로 시작·종료 시간을 조절합니다. −/+는 한 프레임씩 이동합니다.
• 드래그 취소: Esc. 실행 취소: ⌘Z. 다시 실행: ⇧⌘Z.
• 상세 구간 듣기는 준비된 음성을 사용하며 영상은 정지 화면을 유지합니다.
  영상 재생은 미리보기 재생 버튼 또는 전체 타임라인 Space를 이용하세요.
• 사용자 단축키는 키보드 모양 버튼에서 설정합니다.

자막 스타일과 반응형 배경 (v1.6)
• 이 Mac에 설치된 폰트, 굵기, 크기, 자간, 줄 간격, 글자색과 위치를 설정합니다.
• ‘테두리’ 체크를 끄면 외곽선을 제거합니다. 다시 켜면 기존 두께를 사용합니다.
• 글자색·테두리색·그림자색·배경색 버튼으로 앱 안의 색상 팔레트를 엽니다.
• ‘내 스타일 저장’으로 사용자 설정을 보관합니다. 제작자의 개인 스타일·폰트는 포함하지 않습니다.
• ‘파컷 스타일 가져오기’는 저장된 글자 스타일을 미리 보여줍니다.
  목록이 비어 있으면 폴더 직접 찾기/파일 직접 찾기로 사용자 저장 위치를 연결하세요.
  지원되는 2D 속성을 가져오며 일부 3D·애니메이션·효과는 재현하지 못합니다.
• ‘반응형 배경 박스’를 켜면 문장 길이와 줄 수에 맞춰 배경이 늘어납니다.
  배경색·불투명도·좌우/상하 여백·모서리를 조절할 수 있습니다.
• 선택 자막 적용/전체 자막 적용으로 반영합니다. 파컷에 보낸 뒤 글자를 바꿔도 박스가 따라갑니다.
• 반응형 타이틀은 앱에 포함되어 자동 설치됩니다. Apple Motion 앱을 별도로 구매할 필요는 없습니다.
  동일한 타이틀이 있으면 다시 설치하지 않습니다. 파일 접근 권한은 macOS에서 요청할 수 있습니다.
• 수정하지 않은 v1.6 시험판 타이틀은 백업 후 안정화된 타이틀로 교체합니다.
  직접 수정된 타이틀은 덮어쓰지 않고 안내합니다. 업데이트 전 파컷을 종료하세요.
• 자막 폭에 맞춘 줄바꿈은 기존 시간을 유지합니다. AI 받아쓰기를 다시 실행하지 않습니다.
• 상세 음성 편집은 필요할 때 펼쳐 사용합니다. 평소에는 닫아 두어 자막 이동 부담을 줄였습니다.
• SRT에는 글꼴·색·배경을 저장할 수 없습니다. 스타일은 옥자막 프로젝트와 파컷 타이틀에 반영됩니다.

프로젝트와 음성 처리
프로젝트의 컷 위치와 시간을 기준으로 음성을 먼저 준비합니다.
영상 미리보기의 문제만으로 받아쓰기를 막지 않습니다.
비활성 클립·음소거·지원되는 채널 음소거·음량 키프레임·페이드를 반영합니다.
지원하지 않는 음성 편집은 해당 구간을 건너뛰고 시간과 이유를 보고합니다.
건너뛴 구간의 시간을 줄이거나 뒤 자막을 당기지 않습니다.
음질 보정 효과를 생략해 원본 음성을 읽은 경우도 상세 보기에 표시합니다.
완성 음성 연결은 필요한 경우의 선택 사항입니다.

파컷으로 보내기와 파일
파컷에는 원래 편집 구조를 보존하고 편집 가능한 타이틀 자막을 더한 새 프로젝트로 보냅니다.
새 자막은 ITT 캡션이 아닙니다. 기존 프로젝트에 이미 있던 캡션·타이틀은 유지됩니다.
일반 자막 파일은 UTF-8 SRT로 저장합니다. 번역 기능은 포함하지 않습니다.
기본 작업 파일은 .okjamak 입니다. .hancap / .okjamakaudio / .okjamakedit도 읽습니다.
직접 저장한 프로젝트·원본 미디어를 옥자막 제거 앱이 삭제하지 않습니다.

알려진 범위와 한계
• 파컷의 최종 영상·오디오 믹스를 완전히 재현하는 렌더러는 아닙니다.
• 배속(timeMap), 멀티캠·오디션, 역할별 음성 선택, 채널별 시간 편집 등
  지원하지 않는 음성 구간은 건너뛰고 알립니다. 정상 구간은 계속 처리합니다.
• 일부 효과·패닝·트랜지션 혼합은 생략될 수 있습니다. 상세 보고를 확인하세요.
• 원본 오디오 파일 자체가 없거나 접근할 수 없으면 음성을 복원할 수 없습니다.
• 음악·잡음 속 대사는 오인식될 수 있습니다. 반복 감지/재인식은 완전한 교정을 보장하지 않습니다.
• ‘말소리 구간별 받아쓰기’는 선택형 시험 기능입니다. 작은 목소리는 놓칠 수 있습니다.
• 단어별 자동 시간 정렬은 제공하지 않습니다. 특히 Qwen 시간과 Enter 분할 시간은 추정값입니다.

제거와 클린 재설치
1. 작업을 저장하고 옥자막과 파컷을 종료합니다.
2. ‘옥자막 제거.app’을 열어 제거 목록을 확인합니다.
3. 기본 선택은 일반판 앱과 그 안의 파컷 확장만 휴지통으로 이동합니다.
4. 클린 재설치가 필요하면 ‘설정·자동 복구본·기본 위치의 다운로드 모델도 제거’를 선택합니다.
   필요한 복구 작업을 먼저 프로젝트 파일로 저장하세요.
5. 제거가 끝나면 OKjamak.app을 다시 응용 프로그램으로 복사합니다.
사용자가 지정한 별도 모델 폴더·원본 미디어·저장한 프로젝트·다른 사용자의 데이터는 보존합니다.
음성기준/음성편집 시험판도 보존합니다. 시험판 폴더를 별도 모델 폴더로 연결했다면 그 폴더는 보존합니다.
제거 앱 자체는 닫은 뒤 직접 휴지통으로 옮기면 됩니다.

처리와 라이선스
받아쓰기는 이 Mac에서 처리합니다. 앱에 포함된 제3자 코드·모델 라이선스는
OKjamak.app/Contents/Resources의 LICENSE 파일들에 들어 있습니다.

반응형 배경 타이틀 보존 (v1.6 이후)
새 옥자막에는 자체 반응형 타이틀과 설치 도우미가 포함됩니다. 처음 앱을 실행하거나 반응형 자막을 파컷으로 보낼 때 자동으로 준비합니다. 이미 만든 파컷 프로젝트를 보호하기 위해 제거 앱은 ~/Movies/Motion Templates.localized/Titles.localized/OKjamak 아래의 전용 타이틀을 삭제하지 않습니다. 이 타이틀을 쓰는 프로젝트가 없고 완전 제거를 원할 때만 해당 폴더를 별도로 보관하거나 삭제하세요. 다른 사용자 타이틀 폴더는 제거 대상이 아닙니다.
