옥자막 (OKjamak) v 1.0.0
한국어 자막 편집기 · Final Cut Pro Workflow Extension

[설치]
1. DMG를 열고 OKjamak.app을 옆의 ‘응용 프로그램’ 폴더로 드래그하세요.
2. 복사가 끝나면 DMG를 추출하고 응용 프로그램 폴더에서 옥자막을 한 번 실행하세요.
3. Final Cut Pro를 다시 실행한 뒤 윈도우 → 확장 프로그램 → 옥자막을 여세요.
4. 파컷 브라우저의 프로젝트 하나를 옥자막 위쪽 드롭 영역으로 드래그하세요.
5. 미디어 접근 안내가 나오면 원본이 있는 폴더를 선택해 접근을 허용하세요.
6. 한국어 받아쓰기 → 자막 편집 → 파컷으로 보내기 순서로 사용하세요.

새 Mac에서도 기존 설정이나 별도 개발 도구 없이 시작할 수 있습니다.
Whisper Base 다국어 모델과 음성 인식 엔진을 포함했습니다.
더 큰 모델은 ‘모델 선택·다운로드’에서 내려받으세요. 추가 모델을 받으려면 인터넷이 필요합니다.
다운로드 후 받아쓰기는 Mac 내부에서 처리합니다.

[최초 실행 / 서명 상태]
이 배포본은 로컬 서명(ad-hoc)이며 Apple Developer ID 서명·공증을 받지 않았습니다.
인터넷으로 받은 경우 macOS가 실행을 막을 수 있습니다.
출처를 신뢰하고 실행하려는 경우에만 시스템 설정 → 개인정보 보호 및 보안에서
해당 앱의 ‘확인 없이 열기’를 사용하세요. 제거 앱도 별도 실행 확인이 필요할 수 있습니다.
전역 보안 설정을 끄거나 터미널 명령으로 보안을 해제할 필요는 없습니다.
회사 관리 Mac 등에서는 관리자 정책에 따라 실행할 수 없을 수 있습니다.
Apple 안내: https://support.apple.com/ko-kr/102445

[지원 환경]
macOS 15.0 이상 · Apple Silicon 및 Intel 공용 앱
실제 검증 환경: macOS 15.7.4, Intel Mac, Final Cut Pro 12.3.
Apple Silicon용 실행 파일도 포함하지만 해당 하드웨어에서 실행 검증하지는 않았습니다.
파컷 확장을 사용하려면 Final Cut Pro가 별도로 설치되어 있어야 합니다.
기본 모델은 약 150MB이며 설치 앱 전체는 약 160MB입니다.

[자막 편집]
↑ / ↓ : 자막 문구 편집 중 이전 / 다음 자막으로 커서 이동
Enter : 커서 위치에서 자막 나누기
맨 앞에서 Backspace : 앞 자막과 합치기
Shift+Enter : 같은 자막 안에서 줄바꿈
Shift+방향키 : 글자 선택
한글 조합 중 방향키는 입력기 동작을 유지합니다.
검색 중에는 표시된 자막 사이로 이동합니다.
Space : 재생 / 정지 (문구 입력 중에는 공백 입력)
⌘Z / ⇧⌘Z : 실행 취소 / 다시 실행

[업데이트 / 클린 설치]
기존 사용자는 작업을 .okjamak 파일로 저장하고 옥자막·Final Cut Pro를 종료한 뒤
응용 프로그램 폴더의 이전 앱을 새 앱으로 교체하세요. 기존 모델·작업·설정을 이어서 사용합니다.
예전 HanCap.app이 함께 있으면 ‘옥자막 제거’에서 앱만 제거한 뒤 새 앱을 복사하세요.
완전히 초기화하려면 아래 추가 정리 옵션으로 제거한 뒤 다시 설치하세요.
프로젝트 파일과 원본 미디어는 따로 보관하세요.

[제거]
1. 작업을 저장하고 옥자막과 Final Cut Pro를 종료하세요.
2. 이 DMG의 ‘옥자막 제거.app’을 실행하세요. 필요하면 먼저 Mac에 복사해도 됩니다.
3. 표시된 경로를 확인하고 ‘휴지통으로 이동’을 누르세요.
기본 선택: /Applications 또는 ~/Applications의 옥자막·한캡 앱과 그 안의 파컷 확장만 제거.
추가 선택: 현재 사용자의 설정, 자동 복구본, 기본 위치 다운로드 모델, 앱 캐시도 휴지통으로 이동.
직접 지정한 외부 모델 폴더와 일반 문서 폴더에 저장한 .okjamak/.hancap/SRT,
원본 영상, 파컷 보관함은 제거 대상이 아닙니다.
제거 앱은 삭제한 항목을 휴지통에 보관합니다. 휴지통을 비우기 전까지 저장 공간은 반환되지 않습니다.
관리자 소유 앱이나 보호된 데이터는 옮기지 못할 수 있습니다. 실패한 경로는 결과 창에 표시됩니다.
표준 설치 위치 밖의 개발용·백업 앱 사본은 직접 정리하세요.
제거 앱 자체는 닫은 뒤 휴지통으로 옮기거나, 이 DMG를 추출하면 됩니다.

[데이터 위치]
~/Library/Application Support/HanCap/
~/Library/Containers/local.hancap.editor.workflow/
내부 이름 HanCap은 기존 버전의 설정·모델·작업 호환성을 위해 유지합니다.
추가 정리는 위 폴더 전체를 이동하므로 그 안에 따로 보관한 파일이 있으면 먼저 꺼내세요.
사용자가 지정한 외부 모델 폴더는 제거 앱이 따라가서 삭제하지 않습니다.

[파컷 지원 범위]
일반 컷·연결 클립·기본 음량·자동 프레임 맞춤을 읽어 미리보기와 음성을 구성합니다.
기존 프록시가 프로젝트에 제공되면 우선 사용합니다. 새 프록시를 자동 생성하지 않습니다.
속도 변경(timeMap)·멀티캠·트랜지션·복잡한 오디오 효과 등은 편집본 연결이 필요할 수 있습니다.
파컷의 색보정·기존 타이틀·영상 효과 전체를 옥자막 미리보기에서 재현하지는 않습니다.
새 자막은 편집 가능한 기본 타이틀로 새 프로젝트에 추가합니다. 원래 프로젝트는 그대로 유지합니다.
자동 번역은 제공하지 않습니다. 받아쓰기 결과와 자막 타이밍을 확인한 뒤 사용하세요.
