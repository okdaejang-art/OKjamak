# 옥자막 · OKjamak

Mac에서 한국어 자막을 만들고 편집하는 앱입니다. 독립 앱으로 실행하거나 Final Cut Pro의 **윈도우 → 확장 프로그램 → 옥자막**에서 사용할 수 있습니다.

**현재 버전: v 1.0.0** · macOS 15.0 이상 · Intel / Apple Silicon 공용

## 다운로드와 설치

이 저장소의 **Releases → v1.0.0 → Assets**에서 **`OKjamak-1.0.0-macOS.dmg`**를 내려받으세요.

1. DMG를 열고 `OKjamak.app`을 **응용 프로그램** 폴더로 드래그합니다.
2. 복사가 끝나면 DMG를 추출하고, 응용 프로그램 폴더의 옥자막을 한 번 실행합니다.
3. Final Cut Pro를 다시 실행한 뒤 **윈도우 → 확장 프로그램 → 옥자막**을 엽니다.
4. 파컷 브라우저의 프로젝트 하나를 옥자막 상단에 드래그합니다.
5. **한국어 받아쓰기 → 자막 편집 → 파컷으로 보내기** 순서로 사용합니다.

기본 Whisper Base 모델과 음성 인식 엔진을 포함했습니다. 처음 사용하기 위해 별도의 개발 도구를 설치할 필요가 없습니다. 더 큰 AI 모델은 앱의 **모델 선택·다운로드**에서 선택하세요.

이 배포본은 **Apple Developer ID 서명·공증 전**입니다. 인터넷으로 받은 앱은 최초 실행 시 macOS에서 차단될 수 있습니다. 출처를 신뢰할 경우의 실행 방법은 [Apple 공식 안내](https://support.apple.com/ko-kr/102445)를 확인해 주세요. 관리되는 Mac에서는 조직 정책에 따라 실행이 제한될 수 있습니다.

## 주요 기능

- 한국어 메뉴와 한국어 받아쓰기
- Mac 내부 음성 인식, 여러 모델 선택·다운로드
- FCPXML 프로젝트 불러오기와 기본 편집 구조를 이용한 미리보기
- 프로젝트 해상도·화면 비율·프레임 속도 유지
- 프로젝트에서 제공하는 기존 프록시 우선 사용
- 자막 문구·시간 편집, 분할·병합·실행 취소
- SRT 저장, 편집 가능한 기본 타이틀을 추가한 새 파컷 프로젝트로 보내기
- `.okjamak` 프로젝트 저장, 기존 `.hancap` 작업 열기

## 편집 단축키

| 키 | 동작 |
|---|---|
| ↑ / ↓ | 문구 편집 중 이전 / 다음 자막으로 커서 이동 |
| Enter | 커서 위치에서 자막 나누기 |
| 맨 앞에서 Backspace | 앞 자막과 합치기 |
| Shift+Enter | 자막 안에서 줄바꿈 |
| Space | 재생 / 정지, 문구 입력 중에는 공백 입력 |
| ⌘Z / ⇧⌘Z | 실행 취소 / 다시 실행 |

한글 조합 중 방향키는 입력기 동작을 유지합니다. 검색 중에는 표시된 자막 사이로 이동합니다.

## 제거와 초기화

DMG에 들어 있는 **옥자막 제거.app**을 실행하세요. 작업을 저장하고 옥자막과 Final Cut Pro를 종료한 뒤 진행합니다.

- 기본 선택은 앱과 내장 파컷 확장만 휴지통으로 옮깁니다.
- 추가 정리를 선택하면 현재 사용자의 설정·자동 복구본·기본 위치의 다운로드 모델도 옮깁니다.
- 별도로 저장한 프로젝트, 원본 영상, 파컷 보관함과 직접 지정한 외부 모델 폴더는 제거 대상이 아닙니다.

상세 경로와 안내는 [설치와 제거 안내](INSTALL-ko.txt)를 참고하세요.

## 지원 범위와 검증 환경

일반적인 컷·연결 클립·기본 음량·자동 프레임 맞춤을 지원합니다. 별도 속도 변경, 멀티캠, 트랜지션, 복잡한 오디오 효과 등은 파컷에서 내보낸 편집본 연결이 필요할 수 있습니다. 파컷의 모든 색보정·영상 효과·기존 타이틀을 미리보기에서 재현하지는 않습니다.

자동 번역은 포함하지 않습니다. 음성 인식 결과와 자막 타이밍은 내보내기 전에 확인해 주세요. 영상과 음성은 외부 서버로 전송하지 않으며, 추가 모델 다운로드에 인터넷을 사용합니다.

실제 검증 환경은 **macOS 15.7.4 / Intel Mac / Final Cut Pro 12.3**입니다. Apple Silicon 실행 파일을 포함하지만 해당 실기기와 새 Mac에서의 실행은 별도 검증 대상입니다.
