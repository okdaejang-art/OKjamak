# 옥자막 · OKjamak

Mac에서 음성을 받아쓰고 자막을 만들며, 필요할 때 번역하는 앱입니다. 독립 앱으로 실행하거나 Final Cut Pro의 **윈도우 → 확장 프로그램 → 옥자막**에서 사용할 수 있습니다.

**현재 버전: v2.1.3 (build 36)** · macOS 15 이상 · Intel / Apple Silicon 공용

## 다운로드

**[옥자막 2.1.3 다운로드](https://github.com/okdaejang-art/OKjamak/releases/tag/v2.1.3)**

**v1.6 사용자 안내:** 파컷 확장에서 모델이 0KB로 표시되거나 다운로드되지 않는 문제를 1.6.1에서 수정했습니다. 기존 모델을 지우거나 다시 받을 필요 없이 앱만 교체하세요. 일반판 앱·파컷 확장의 기본 폴더에 받은 모델을 자동으로 찾아 재사용합니다. 별도 폴더 권한 안내가 나오면 ‘모델 폴더 선택…’에서 기존 폴더를 다시 연결하세요.

Assets에서 `OKjamak-2.1.3-macOS.dmg`를 받으세요. ZIP도 제공합니다. 앱·파컷 확장·기본 Whisper Base 모델·제거 앱이 포함됩니다. 추가 모델은 앱의 **모델 선택·다운로드**에서 고를 수 있습니다.

## 설치와 사용

1. DMG의 `OKjamak.app`을 응용 프로그램 폴더로 드래그합니다.
2. 응용 프로그램의 옥자막을 한 번 실행하고 Final Cut Pro를 재시작합니다.
3. 파컷의 **윈도우 → 확장 프로그램 → 옥자막**을 엽니다.
4. 프로젝트 하나를 상단 영역에 놓거나 FCPXML·영상·음성을 엽니다.
5. **받아쓰기 → 자막 확인 → 필요하면 자막 번역 → 파컷으로 보내기 / SRT 저장** 순서로 사용합니다.

**Apple Developer ID 서명·공증 전**입니다. 첫 실행이 차단되면 출처를 확인하고 [설치 안내](INSTALL-ko.txt)와 [Apple 공식 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

## v2.1.3 — 컴파운드 오디오 채널·음성 분리 누락 수정

- 컴파운드 내부에서 분리된 오디오 채널의 원본을 찾지 못해 음성이 빠지던 문제를 수정했습니다.
- 채널 또는 컴파운드 역할에 ‘음성 분리’를 적용했을 때 음성이 누락되던 문제를 수정했습니다.
- 받아쓰기는 효과를 생략한 원본 음성을 사용하며, 채널별 음량·음소거·시간과 파컷으로 내보내는 효과 설정을 보존합니다.

**2.0 이상은 앱의 ‘업데이트 확인…’에서 2.1.3을 받으세요.** 설치 전에 작업을 저장하고 파컷을 종료하세요. 기존 모델·스타일·교정사전은 유지합니다. 이미 빠진 자막은 자동 복구되지 않으므로 프로젝트를 새로 불러와 받아쓰기를 실행해 주세요.

실제 제보 XML과 같은 구조의 테스트 음원으로 검증했습니다. 제보 원본 영상·음성이 없어 실제 대사의 받아쓰기 결과는 아직 확인하지 못했습니다.

같은 종류의 오류를 재현한 테스트는 통과했습니다. 제보자의 실제 프로젝트는 아직 확보하지 못해 추가 확인이 필요합니다.

## v2.1 — 한국어 받아쓰기 개선과 옵션 기억

- **작업 언어 유지:** 자동 감지 + 말소리 구간 인식에서 작업 언어를 한 번 정하고 이후 구간에도 유지합니다. 짧은 한국어 대사가 다른 언어로 인식되는 현상을 줄였습니다.
- **가까운 말소리 함께 인식:** 인접한 구간의 주변 대사를 참고하며 원래 시간 위치를 유지합니다. 추가 AI나 전체 받아쓰기 재실행 단계는 없습니다.
- **마지막 받아쓰기 옵션 기억:** 말소리 구간만 인식·문장 끝 마침표 제거·문장 흐름에 맞춰 자막 나누기를 재실행과 새 작업에도 이어서 사용합니다. 저장한 프로젝트의 설정은 우선합니다.
- 두 받아쓰기 옵션의 이름과 설명을 정리했습니다. 자막 나누기 알고리즘 자체는 2.0과 같습니다.

## v2.0 — 문장 흐름, Intel 최적화, 스타일 기억과 업데이트

- **문장 흐름으로 나누기:** 한국어 Whisper 받아쓰기에서 문장 끝·연결 표현·말 사이 간격과 자막 폭을 참고합니다. 기본 켜짐이며 끄면 기존 글자 수 방식입니다. 별도 LLM이나 분석 버튼은 필요 없습니다.
- **Intel 최적화:** AVX2·FMA·F16C 지원 Intel CPU에서 최적화 엔진을 자동 선택합니다. Apple Silicon과 다른 CPU의 기존 계산 경로는 유지하며 성능 차이는 기기·모델에 따라 다릅니다.
- **마지막 적용 스타일 기억:** 실제 자막에 마지막으로 적용한 스타일을 다음 새 작업에 사용합니다. 저장된 프로젝트는 그 프로젝트의 스타일을 우선합니다.
- **업데이트 확인:** 앱 안에서 확인·다운로드·설치합니다. 자동 확인과 자동 다운로드는 기본 꺼짐이며 사용자가 선택합니다. 작업 중이거나 파컷 실행 중에는 교체를 미룹니다.
- **반응형 박스 높이:** 상하 여백이 파컷에 반영되도록 수정했습니다. 새 내보내기는 포함된 v2 타이틀을 쓰고 기존 타이틀은 보존합니다.

**1.x → 2.0은 한 번 직접 앱을 교체하세요. 2.0부터 이후 업데이트에 앱 내 업데이트 기능을 사용할 수 있습니다.** 기존 모델·스타일·설정을 이어서 사용하므로 제거 앱을 실행하거나 모델을 지우지 마세요. 별도 모델 폴더의 권한 안내가 나오면 기존 폴더를 다시 연결하세요.

`OKjamak-2.0.0-update.zip`과 `appcast.xml`은 앱 업데이트용입니다. 처음 설치하거나 1.x에서 올릴 때는 **macOS.dmg 또는 macOS.zip**을 받으세요.

문장 나누기는 모든 구어체·화자 전환을 완벽히 구분하지 않습니다. 기존 자막을 업데이트만으로 다시 나누거나 기존 파컷 타이틀을 바꾸지는 않습니다. 이번 준비에서는 Intel 실기기로 확인했으며 Apple Silicon 실기기 실행 검사는 하지 않았습니다. [검증 범위](VERIFICATION-ko.txt)를 참고하세요.

## v1.6.2 — 자동 언어 감지와 선택형 번역

- 기본 음성 언어를 자동 감지하며, 필요하면 직접 지정할 수 있습니다.
- 받아쓰기 후 원하는 사람만 **자막 번역**을 실행합니다. 한국어 ↔ 외국어를 지원합니다.
- **원문만 / 원문 + 번역 / 번역만** 선택이 미리보기·SRT·파컷 타이틀에 반영됩니다.
- 원문과 번역은 따로 저장하고 기존 자막 시간은 유지합니다.
- 번역문을 직접 고치고, 변경된 원문이나 빠진 번역만 다시 번역할 수 있습니다.
- macOS 내장 번역을 사용하므로 별도 번역 AI 앱이나 유료 API 키는 필요 없습니다.
- 번역 언어 파일은 처음 사용할 때 다운로드할 수 있습니다. 기존 Whisper 음성 모델은 재사용합니다.

원문을 먼저 검토한 뒤 번역하고, 이름·애칭·배경음악이 있는 구간은 결과를 확인해 주세요.

## v1.6 주요 변화

- 글꼴·굵기·크기·자간·줄 간격·색·그림자·위치를 설정하고 내 스타일로 저장합니다.
- 파컷에 저장한 글자 스타일의 목록과 미리보기를 제공합니다. 폴더·파일을 직접 연결할 수도 있습니다.
- 앱 안의 색상 팔레트와 색상코드 입력, 명확한 테두리 켜기·끄기를 제공합니다.
- **문장 길이와 줄 수에 따라 늘어나는 반응형 배경 박스**를 지원합니다. 전용 타이틀과 설치 도우미가 포함되어 별도 Motion 구매 없이 자동 설치합니다.
- 시험판에서 반응형 타이틀을 가져오거나 파컷을 종료할 때 발생하던 충돌을 수정했습니다. 수정하지 않은 기존 시험판 타이틀은 백업 후 교체하고 사용자 수정본은 보존합니다.
- 자막 연속 이동의 불필요한 영상 탐색과 화면 갱신을 줄였습니다. 상세 파형은 필요할 때 펼쳐 준비하며 분할·병합·빈 구간 편집은 유지합니다.
- 실제 글자 폭을 기준으로 줄바꿈을 미리 보고 적용합니다. 기존 자막 시간은 유지됩니다.

제작자의 개인 폰트·스타일은 포함하지 않습니다. 각 Mac의 폰트와 사용자 설정을 사용합니다. 파컷 스타일 가져오기는 `.molo` 및 타이틀이 들어 있는 FCPXML의 지원되는 2D 속성을 대상으로 하며 모든 3D·애니메이션 효과를 재현하지 않습니다. SRT는 글자와 시간만 저장하므로 스타일·배경은 포함하지 않습니다.

- 한글 조합 중 커서 이동을 개선하고 ↑↓ 이동 시 다음 자막 맨 앞에 커서를 둡니다.
- 상세 파형·구간 듣기·프레임 조절·글자와 시간을 함께 고르는 분할·빈 자막 구간을 지원합니다.
- 왼쪽 클릭은 위치 지정, Space는 재생·정지로 통일했습니다.
- 원래 편집 구조를 보존한 새 파컷 프로젝트에 **편집 가능한 타이틀 자막**을 추가합니다. ITT 캡션이 아닙니다.

## 편집 방법

| 조작 | 동작 |
|---|---|
| ↑ / ↓ | 이전 / 다음 자막 맨 앞으로 이동 |
| 문장 맨 앞 Space | 미리보기 재생·정지 |
| 문장 중간 Space | 띄어쓰기 |
| 타임라인·파형 왼쪽 클릭 | 재생을 멈추고 위치 고정, 자동 재생하지 않음 |
| 전체 타임라인 Space | 영상 미리보기 재생·정지 |
| 상세 파형 Space | 현재 위치부터 음성 듣기·정지·이어 듣기 |
| 문장 커서 → 파형에서 시간 선택 → 여기서 분할 | 글자는 커서에서, 시간은 선택한 지점에서 분할 |
| 앞을 빈 클립으로 | 선택 지점 앞을 자막 없는 구간으로 분리 |
| Enter / Shift+Enter | 자막 분할(시간 추정) / 문장 안 줄바꿈 |
| 맨 앞 Backspace | 앞 자막과 병합 |
| ⌘Z / ⇧⌘Z | 실행 취소 / 다시 실행 |

상세 파형의 **흰 선은 재생 위치**, **노란 선은 분할점**입니다. 빠른 구간 듣기는 준비된 음성만 재생하며 영상은 정지 화면을 유지합니다. 음성·영상과 뒤 자막 시간은 빈 클립 분할로 삭제되거나 당겨지지 않습니다. 빈 자막은 SRT·파컷에 내보내지 않습니다.

## 기존 사용자 업데이트

작업을 저장하고 옥자막·파컷을 종료한 뒤 응용 프로그램의 앱을 교체하세요. 일반판 1.x의 모델·설정 위치와 사용자 단축키를 유지합니다. 업데이트를 위해 제거 앱을 먼저 실행할 필요는 없습니다.

음성기준·음성편집 시험판은 별도 앱으로 보존됩니다. `.okjamakaudio` / `.okjamakedit` 작업을 저장해 v1.6에서 열고 `.okjamak`으로 따로 저장하세요. 시험판 모델은 기존 모델 폴더 연결 기능으로 재사용합니다. 자동 복구본과 모델을 자동 이전하지는 않습니다. 기존 `.hancap`도 열 수 있습니다.

## 지원 범위와 한계

지원되는 컷 편집·음소거·채널 선택·음량 키프레임·페이드를 음성에 반영합니다. 곡선은 내부에서 근사합니다. 컴파운드의 정적인 역할별 음량·음소거·채널 선택도 지원합니다. 배속(timeMap), 멀티캠·오디션, 역할별 시간 편집·음량 자동화, 채널별 시간 편집 등 미지원 음성 구간은 건너뛰고 보고합니다. 일부 보정 효과·패닝·트랜지션 혼합은 생략될 수 있습니다. **상세 보고를 확인하세요.**

원본 오디오가 없거나 접근할 수 없으면 복원할 수 없습니다. 영상 효과·색보정·기존 타이틀 등 파컷의 최종 결과를 모두 재현하는 미리보기는 아닙니다. 필요한 경우 파컷에서 내보낸 완성 음성을 선택적으로 연결할 수 있습니다.

음악·잡음 속 대사는 틀릴 수 있으며 반복 감지·재인식이 완전한 교정을 보장하지 않습니다. ‘말소리 구간별 받아쓰기’는 선택형 시험 기능으로 작은 목소리를 놓칠 수 있습니다. 단어별 자동 시간 정렬은 제공하지 않습니다. 번역은 macOS 내장 번역의 지원 언어 목록에서 선택하며, 처음 사용하는 언어는 다운로드가 필요할 수 있습니다. 받아쓰기는 Mac 안에서 처리하며 추가 모델 다운로드에는 인터넷을 사용합니다.

실제 실행·입력·오디오 검사는 **Intel Mac / macOS 15.7.4**에서 진행했습니다. Apple Silicon은 빌드·파일 검사를 완료했으며 이번 별도 실기기 실행은 하지 않았습니다. v1.6 배포 당시 Final Cut Pro 12.3의 별도 QA 보관함에서 실제 전송·반복 가져오기·종료·재실행과 반응형 타이틀 새 설치를 확인했습니다. 4K 60fps 합성 프로젝트에 타이틀 1,000개를 넣어 가져오기와 표시를 검사했습니다. 실제 50분 영상을 처음부터 끝까지 재생한 검사는 아닙니다. 상세 결과는 릴리스의 VERIFICATION-ko.txt에 있습니다.

## 제거와 클린 재설치

**옥자막 제거.app**은 기본적으로 일반판 앱과 내장 확장을 휴지통으로 옮깁니다. 선택하면 현재 사용자의 설정·자동 복구본·기본 위치의 다운로드 모델도 정리할 수 있습니다. 원본 미디어·파컷 보관함·직접 저장한 프로젝트·별도 모델 폴더·시험판은 보존합니다. 이미 만든 파컷 프로젝트를 보호하기 위해 설치된 반응형 타이틀도 보존합니다. 작업을 먼저 저장하고 옥자막과 파컷을 종료하세요. [설치와 제거 안내](INSTALL-ko.txt)를 확인해 주세요.
