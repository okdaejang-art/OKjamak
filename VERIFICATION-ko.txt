옥자막 2.1.3 / build 36 검증 범위
2026-11-07

- 기존 2.1.2 정식판에서 오디오 불러오기 두 파일과 버전 표시만 변경했습니다.
- 실제 제보 FCPXML 1.14에서 2.1.2의 채널 원본 조회 실패를 재현했습니다.
- 수정 후 컴파운드 106개 구간의 212개 오디오 채널 구간이 복원되고, 원래 읽히던 26개 일반 클립과 전체 길이가 유지됨을 검사했습니다.
- 원본 시작 시간, 컴파운드 잘라내기, 채널별 음소거·음량과 연결 오디오의 독립적인 설정을 검사했습니다.
- 동일 구조의 20초 스테레오 테스트에서 추출 PCM이 채널·시간·음량을 직접 지정한 기준 음원과 바이트 단위로 일치했습니다.
- 실제 파컷에서 내보낸 리미터·MultiMeter 및 40% 음성 분리 프로젝트를 검사했습니다.
- 일반 채널·컴파운드의 EQ, 매치 EQ, 패닝, 비활성 효과, 음성 분리, 리미터·MultiMeter 등 16가지 합성 사례를 검사했습니다.
- 지원하지 않는 구간 음소거·알 수 없는 편집을 임의로 활성화하지 않는 보호 동작을 검사했습니다.
- 원본 효과·채널·역할·음량 설정을 XML 내보내기에 보존하며, 생성 XML 41개가 해당 공식 DTD를 통과했습니다.
- 정식 번들 식별자·아키텍처·코드 서명, 업데이트 ZIP·피드 서명과 기존 버전의 업데이트 감지를 검사합니다.

제한
제보 ZIP에는 원본 영상·음성이 없어 해당 대사의 실제 받아쓰기 결과는 아직 확인하지 못했습니다.
Apple Silicon 실행 파일을 포함하지만 이번 실행 검사는 Intel Mac에서 수행했습니다.
옥자막은 파컷의 모든 오디오 효과를 재현하는 렌더러가 아닙니다. 음성 분리·리미터 등 효과를 생략한 원본 음성으로 받아씁니다.
일부 역할별 시간 편집·음량 자동화 등은 지원하지 않으며 불러오기 결과에 안내합니다.
Apple Developer ID 서명·공증 전입니다. Sparkle 업데이트 서명은 Apple 공증과 다릅니다.
